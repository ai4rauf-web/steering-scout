# Steering Scout

A design exploration for Property Finder's conversational property search — how a user can see what Scout has understood about them, disagree with or correct it, and steer the experience, mid-conversation, on a 375-pixel mobile screen, using one hand, without a filter panel.

**Live:** the deployed URL from Vercel.
